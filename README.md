# DEEPOTSAV — The Grand Diwali Mela

A browser-based procedural 3D Diwali fairground.

## Run in VS Code
1. Extract `Deepotsav-Mela.zip`.
2. Open the extracted `Deepotsav-Mela` folder in VS Code.
3. Install the **Live Server** extension if needed.
4. Right-click `index.html` and choose **Open with Live Server**.
5. Keep an internet connection active: Three.js is loaded from jsDelivr.

You can also use another local web server. Opening `index.html` directly with `file://` may be blocked by browser module security rules.

## Controls
- `W`, `A`, `S`, `D` or arrow keys: move.
- `Shift`: move faster.
- `E`: interact with a nearby shop.
- Drag the mouse: rotate the camera.
- `V` or **Self View**: switch to a front-facing camera view.
- **Wardrobe**: change character gender, name, and collected outfit.
- **Mela Map**: view the market and attractions directory.
- Touch screens: use the on-screen directional pad.

## Included
- Procedural 3D fairground, stalls, pathways and traditional decorations.
- Diyas, rangoli, decorative lights and animated visual fireworks.
- Ferris wheel, carousel and swing ride models.
- Visitors and families in traditional-inspired clothing, plus pet dogs.
- Free shop purchases, wardrobe and collection UI.

## Notes
- No npm install or build step is required.
- The project needs internet access for the Three.js CDN import.
- Fireworks are visual effects only; there are no instructions or simulations for handling real firecrackers.
- This is a first playable build. Detailed cloth physics, ride boarding, conversations and saved inventory are not included.
